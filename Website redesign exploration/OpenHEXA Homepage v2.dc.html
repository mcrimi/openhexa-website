Questions

What does the trial include?+

Every feature, including the pipeline assistant, the MCP server and the web app builder. There is no AI add-on and no sales call to get started.

Can I self-host instead?+

Yes. The platform is AGPL-3.0 and runs with docker compose for a local install, or with the Kubernetes charts for a production deployment. Nothing is held back from the self-hosted version.

Do I need to write Python?+

Not to start. Template pipelines cover common tasks such as reading a DHIS2 instance and publishing a dataset. Python and R are there when you need to write the logic yourself.

Where does my data live?+

On the hosted version, in the workspace database and object storage attached to your organization. Self-hosted, in your own infrastructure. Either way, sharing outside the workspace is explicit.

How does the MCP server handle permissions?+

An agent connects with a member's token and sees exactly what that member can read, nothing more. Access is read-only by default.
