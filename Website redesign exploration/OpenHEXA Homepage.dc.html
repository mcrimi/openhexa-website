The product

One workspace, from the source system to the thing people open every morning

01 / CONNECT

Connections

Standard adapters for the systems your programs already run on, plus custom connectors when the source is yours alone. Credentials stay in the workspace, not in someone's script.

02 / BUILD

Pipelines

Write the transformation in Python or R, run it on a schedule, keep every version and every run. Quality checks fail loudly instead of quietly shipping a wrong number.

With AI — describe the pipeline you need and the assistant drafts the code, which you review like any other commit.

03 / GOVERN

Datasets and notebooks

Published datasets are versioned, documented and shareable outside your organization on your terms. Analysts explore them in a JupyterHub that is already wired to the workspace.

With AI — the MCP server exposes those datasets to your own coding agent, under the same permissions.

04 / PUBLISH

Web apps and dashboards

Ship a web app from the workspace, or plug Tableau, Power BI, Superset or Metabase into the same governed tables. Program teams get a URL, not an export.

With AI — the web app builder turns a described view into a working app you can edit by hand afterwards.

Drop your own screenshots into the frame — one per step.

AI in the workspace

Not an AI platform. A data platform your AI tools can reach.

Three things shipped this year, all inside the same permissions model as everything else. No separate product, no add-on: every AI feature is included in the trial.

01

MCP server

Point Claude, Cursor or any MCP client at your workspace and it can query the datasets you already granted it. Read-only by default, scoped to the member's own permissions.

02

Pipeline assistant

Describe the transformation, get a draft pipeline in Python. It lands as reviewable code in a version, not as a black box you have to trust.

03

Web app builder

Turn a published dataset into a working app for program teams, then keep editing it by hand.
